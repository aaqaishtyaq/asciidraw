ASCII art, drawn like a Mac app.

Boxes, lines, diamonds, and FIGlet banners live on a character grid. The picture is text, so it drops into a README, a source comment, or a terminal.

Download for macOS View source

Requires macOS 26 or later. Free.

Plain text

The picture is characters.

Diagrams, layouts, flow charts, data structures, and data formats stay as text, so they embed almost anywhere. PNG and SVG are there when the picture has to be an image.

Diagrams

A diagram next to the code is easier to reread than the code alone. Rectangles, text, lines, and diamonds land on the same cells. The rulers count those cells.

Mind mapping

Put a note anywhere on the canvas and draw a line to the next one. The map does not have to follow the order of a text file.

        notes
          |
    +-----+-----+
  ideas       later

ER diagrams

A line can end in an arrow or in one of three Crow’s foot marks: many, one or many, and zero or many.

 orders
   |
  >+<
   |
 customers

Banners

One click drops a FIGlet banner. block, slim, and standard are included. Load any other .flf from the inspector, then resize the frame and change the alignment.

Text

Double-click the canvas to type. Alignment, position, line sweep, and line movement sit in the inspector. A border is a checkbox.

Lines

Orthogonal or staircase, with a dash pattern. Drag an endpoint onto a shape to attach it. Option-click a border to leave a point the line can stick to.

Rectangles

A single or double border, a fill, and a shadow. Attachment points sit on the border, so a line meets the box where you placed it.

Command line

The asciidraw command ships inside the app. It prints a saved document, or writes the same document back out as JSON.

/Applications/AsciiDraw.app/Contents/SharedSupport/asciidraw Diagram.asciidraw
/Applications/AsciiDraw.app/Contents/SharedSupport/asciidraw --json Diagram.asciidraw

Drawing

Pencil, eraser, bucket fill, and the picker. Each one is a single key, with no modifier.

  • V select, R rectangle, D diamond, T text, S surface
  • L line, P pencil, E eraser, B bucket, K picker
  • A banner, H pan. Space pans, then restores the tool.

MCP

While AsciiDraw is open, asciidraw-mcp speaks MCP on stdio. Claude and other clients can read the canvas and edit the document.

{
  "mcpServers": {
    "asciidraw": {
      "command": "/Applications/AsciiDraw.app/Contents/MacOS/asciidraw-mcp"
    }
  }
}
  • read_canvas, list_shapes
  • add_shape, set_text, set_frame
  • delete_shapes, select_shapes, set_zoom

Around the canvas

Groups

Group shapes, then duplicate or move them as one object. Ungroup puts the pieces back.

Guides

Alignment guides appear while you move and resize, so the edges meet without counting cells.

Focus

Lock or hide the shapes you are not working on, then zoom in on what is left.

Shortcuts

Tools are one key, with no modifier. The menus still show the command for everything else.

Made for the Mac

SwiftUI and AppKit, on the character grid. Undo is always there. Copy as Text puts the picture on the pasteboard. View → Appearance follows the system, or locks light or dark.

A document is a .asciidraw file. Finder opens it in AsciiDraw. The sidebar library keeps those files in folders on this Mac.

Questions

Is it free?
Yes. There is no license and no store. The source is on GitHub.
What are the system requirements?
macOS 26 or later.
How many FIGlet fonts are included?
Three: block, slim, and standard. The inspector can load another .flf.
Where is the command line tool?
/Applications/AsciiDraw.app/Contents/SharedSupport/asciidraw
Where does MCP connect?
To the running app, on a socket under /tmp that belongs to your user. Nothing listens on the network.
How do I send feedback?
Open an issue on GitHub.
